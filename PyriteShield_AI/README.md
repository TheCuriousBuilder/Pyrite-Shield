# PyriteShield AI v1.1

- Highlight: Explain, Rewrite, Summarize, Translate, Ask  
- Any page: Summarize page  
- YouTube: Summarize video from **captions/transcript** (not title-only)

## API keys

Bring **your own** key. Supports:

- OpenAI-compatible base URL (Groq, OpenRouter, OpenAI, local, …)
- Google Gemini

No built-in shared key (would be extracted and abused).

## Install

Load unpacked from this folder in `chrome://extensions`.
