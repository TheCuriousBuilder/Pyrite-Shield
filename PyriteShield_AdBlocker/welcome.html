What this extension does

  • Blocks ads, trackers, cryptominers, and many annoyances
  • Extra handling for YouTube, Twitch, Facebook, and streaming sites
  • Protects common product sites (Google, Microsoft, Apple, ChatGPT, banks, etc.)
  • Optional history pause: strip visits from Chrome history while logging them only in the extension

How to use it

  • Click the Pyrite Shield icon in the toolbar
  • ON/OFF toggles blocking globally
  • Pause disables blocking for the current site only
  • Zap hides leftover elements on a page
  • Support opens GitHub issue templates if something breaks

Permissions (why Chrome asked)

  • Read and change data on websites — required to hide ads
  • History — only used if you turn on history pause / clear
  • Blocking runs on your device. We do not sell your data.

If a site looks broken

  • Open the popup → Pause for that site
  • Or use Support → Website broken
  • Reload the tab after changing settings

  • Pin the extension icon so you can find it later
