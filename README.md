# PyriteShield

A collection of privacy and utility-focused browser extensions built to improve the web without sacrificing performance or user privacy.

## About

PyriteShield is an umbrella project containing browser extensions that focus on privacy, security, quality of life improvements, and useful web utilities. Each extension is designed to be lightweight, straightforward, and respectful of the user's data.

## Goals

* Privacy-first design
* Lightweight and efficient
* Minimal permissions
* No telemetry
* No ads
* Open source
* Modern browser support

## Extension Categories

### Privacy

Extensions that help reduce tracking, improve anonymity, and give users greater control over their browsing experience.

### Security

Tools that improve browser security, highlight potential risks, and help users make safer decisions online.

### Utilities

General-purpose extensions that streamline browsing, automate repetitive tasks, and improve everyday usability.

### Quality of Life

Small enhancements that make websites cleaner, faster, and easier to use.


## Principles

* Do one thing well.
* Request only the permissions that are necessary.
* Never collect user data without explicit consent.
* Keep resource usage as low as possible.
* Stay transparent through open-source development.

## Supported Browsers

* Chromium-based browsers (Chrome, Edge, Brave, Opera, etc.)
* Firefox (where supported)
